# 🌦️ Kazakhstan Weather Telegram Bot

A Telegram bot that provides current weather and 10-day forecasts for cities in Kazakhstan in both **Russian** and **English**.

## ✨ Features

- Current weather
- 10-day weather forecast
- 🇷🇺 Russian language support
- 🇬🇧 English language support
- Fast responses with caching
- Telegram inline keyboard
- Automatic weather parsing from trusted weather services

## 🛠 Technologies

- Python 3.11+
- python-telegram-bot
- BeautifulSoup4
- aiohttp
- aiocache
- asyncio

## 📦 Installation

Clone the repository:

```bash
git clone https://github.com/Dimash357/Kazakhstan-weather-telegram-bot.git
cd Kazakhstan-weather-telegram-bot
```

Install dependencies:

```bash
pip install -r requirements.txt
```

## ▶️ Run

```bash
python main.py
```
